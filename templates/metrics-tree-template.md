# 指标树模板

> 生成者:`product-blueprint-writer` 第 7 步(最后)
> 铁律:北极星依赖前六步取定;**先给过程指标**,增量/结果指标需基线立住+可归因才承诺。

## 一、北极星(唯一,长期)
- 北极星指标: ____
- 它如何可测/可归因? ____
- ⚠ 基线立得住吗?(不可证伪的北极星 MVP 期别硬给)

## 二、指标树
```
北极星: ____
├─ 过程指标(先立住,可每天追)
│   ├─ 例:到期跟进覆盖率
│   ├─ 例:结果回写率
│   └─ 例:出表自动化率(原来人肉现在系统自动)
└─ 结果/增量指标(需基线+归因才承诺)
    ├─ 例:续约率救回 X 点
    ├─ 例:流失率降低 Y
    └─ 例:增量收入 = X点×户数×户均年费
```

## 三、反指标(不想要的副作用)
| 反指标 | 说明(为什么不要) |
|--------|-----------------|
| 例:手工录入负担 | 没人愿填,数据成空 |
| 例:一线为完成任务而录假数 | 质量失真 |

## 四、可测性自检
- [ ] 每个过程指标有数据来源、可日/周追踪?
- [ ] 结果指标有历史基线对比 + 对照组/归因方法?
- [ ] 有没有"做了但测不出变好"的指标?→ 该砍或降级为过程指标。
