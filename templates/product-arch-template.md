## 一、分层架构(每一层只用一个切分维度)

```
┌ 客户经营层(自研系统的命门) ──────────────
│  · 跨客户统一视图 / OneID / 交叉销售 / 归因
├ 能力层(KA/流程) ───────────────────────
│  · 需要持续运转的动作(若适用:建模/回流/评估)
├ 数据层(资产/KR) ───────────────────────
│  · 客户主数据 / 合同 / 业务数据(来源标注:现成集成 or 自研)
└ 作业执行层(各业务系统,不自建第二套) ──────
   · 记账 / 报关 / 金融 / 清关(集成调用)
```

## 三、每功能三问(避免重复建设)
- 这个功能,现成系统(销氪等)有没有?
- 这个功能属作业执行还是客户经营层?
- 它是"闭环"还是"拉着好看"(全貌/标签/首页)?→ 立项期多为负担,砍或降级。
